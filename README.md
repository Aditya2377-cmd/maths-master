# **MATHS MASTER**
#### Video Demo: [https://youtu.be/lagV90jeZeU]
#### Description:
The *Maths Master* is an interactive, CLI-based educational game written in Python, inspired by the classic CS50P *Professor* problem set. Designed to test and improve speed arithmetic, this program extends the traditional math drill concept by incorporating dynamic operations, customized difficulty tiers, live session timers, consecutive streak multipliers, and persistent score saving.
The program presents the user with 10 math problems per round. Rather than restricting the user to simple addition, the game allows players to choose from four core arithmetic operations—Addition, Subtraction, Multiplication, and Division. It features 5 distinct difficulty levels ranging from single-digit operations to complex 5-digit calculations. To keep the gameplay rewarding, the application awards standard points for correct answers and grants a **+2 point streak bonus** whenever a player answers 3 consecutive questions correctly on their first attempt. If an incorrect answer or invalid input is given, the program prompts with "EEE", tracks up to 3 attempts per problem, resets the active streak, and displays the correct answer if all tries are exhausted. At the end of every game, the total execution time is calculated using Python's time module and saved along with session statistics into a permanent text file.
### **Key Features & Mechanics**:
 * **Multiple Operations (A, S, M, D)**: Supports Addition, Subtraction, Multiplication, and Integer Division.
 * **5 Difficulty Levels**: Scales dynamically from Level 1 (0–9) up to Level 5 (10,000–99,999).
 * **Streak Bonus System**: Tracks consecutive first-try answers and awards +2 bonus points when hitting a streak of 3 or more.
 * **Live Timer**: Uses time.time() to measure exact completion speed in seconds.
 * **File I/O Record Keeping**: Automatically appends game stats (Level, Operation, Score, and Time) to scores.txt.
 * **Robust Error Handling**: Handles ValueError exceptions for invalid inputs gracefully without crashing.
### **File Overview**:
#### 1. project.py
This is the main application file containing the primary game loop and core helper functions:
 * main(): Orchestrates the overall execution flow, manages the timer, loops through 10 rounds, and triggers score saving.
 * get_op(): Prompts the player to select a valid arithmetic operation (A, S, M, or D).
 * get_level(): Prompts the player to enter a difficulty level between 1 and 5.
 * generate_integer(): Handles random number generation based on level, builds the math prompt, validates user inputs, updates the score/streak, and handles error retries.
 * save_score(): Opens scores.txt in append mode and records the final summary of the session.
 * is_valid_op(), is_valid_level(), is_valid_score(): Pure validator functions designed to verify individual inputs and enable unit testing.
#### 2. test_project.py
This file contains the unit tests for project.py, executed via pytest. It verifies the core logical components without triggering interactive user inputs:
 * test_is_valid_op(): Tests operation selection against valid (A) and invalid (Z) inputs.
 * test_is_valid_level(): Tests difficulty validation against valid (1) and out-of-bound (9) inputs.
 * test_is_valid_score(): Asserts that non-negative integers return valid score states.
#### 3. scores.txt
A plain text log generated by the application. It maintains a historical log of all completed games formatted as:
Level: {level} | Op: {operation} | Final Score: {score} | Time Taken: {total_time}s.
